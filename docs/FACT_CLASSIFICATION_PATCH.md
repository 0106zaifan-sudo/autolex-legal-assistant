# 事实/主张分类范围修复与失败诊断

日期：2026-11-06（北京时间）。工作分支：`feature/multi-provider-deepseek`，基线`62782c4`。本轮没有调用真实模型API、加载实际Secrets或执行付费验收；用户报告的既有真实SIM_B失败不能由本轮离线测试替代或抹去。

## 先分析原因

旧逻辑对每个`kind=事实`条目扫描其所有引用对应的整个`source.text`，而不是该摘录的原文归属范围。`CLAIM_MARKERS`同时包含主张标记（主张、称、陈述、认为、否认、推测、自述、表示）及核实标记（待核实、尚未核实）。因此同一块里“独立客观记录。另一事项尚未核实。”会拒绝前一句；只对quote查关键词又会允许截掉“驾驶人主张”前缀，不能这样改。

逐项核对`make_acceptance_samples.py`和现有SIM_B解析结果：

| 来源 | 模拟材料内容性质 | 原规则判断 |
|---|---|---|
| S002 | 现场记载碰撞，日期/时刻未记载 | 无CLAIM_MARKERS；单独正确引用本段不会触发此错误 |
| S003 | 2026年11月4日接收检查材料 | 无CLAIM_MARKERS；单独正确引用本段不会触发此错误 |
| S004/S005 | 驾驶人/企业各自主张 | 标事实应拒绝，不能因模拟测试而放行 |
| S006 | 目录仅列出检查摘要，原始车载日志是否完整尚未核实 | 含“尚未核实”，标事实会拒绝；同句内只截“仅列出检查摘要”仍需保守处理 |

**没有取得那次失败的完整结构化响应，旧回执也缺少section/source定位，不能确定实际触发条目，更不能断言SIM_B这次一定是误报。** 若模型把日志完整性标为事实，这次拒绝是正确的；若属于混合来源中另一独立句的污染，则属于已重现的规则缺陷。不能通过改动模拟材料/gold使其通过。

旧逻辑还会漏掉上一个1000字符块或换行前的主张前缀。新增离线测试在旧实现重现了独立句误拒、跨块/换行的归属丢失，以及诊断缺失；修复后均有测试保护。

## 最小修复的边界

`CLAIM_MARKERS`原词表完整保留，不删除关键词、不自动改写分类，也不重试模型。新分类辅助函数从**已经核验的引文坐标**回到当前原始unit：

1. 校验范围保留unit开头至引文的前置上下文，避免截掉说话人、主张或核实限定。范围不随1000字符分块/换行丢失。DOCX unit为解析段落或单元格，PDF unit通常为页。
2. 补齐引文结束所在原文句；逗号、分号不视为核实限定结束。因此`未收到提示，尚未核实`或SIM_B目录的半句不能截取洗成事实。
3. 后续独立句通常不再污染前一句；“上述/前述/该/此”等承接句及直接“待核实/尚未核实”等后置限定仍保守纳入。
4. 对所有引用执行检查，而非只查第一条。宽泛quote自身包含主张/待核实内容仍拒绝；模型应选独立、完整的窄引文。
5. 提示词的一句说明同步更新为保留归属/限定并优先独立完整句。Schema 2.0、版本字段契约、哈希与source生成、时间线句段/时间绑定逻辑没有改动；本次提示文字变更由Git提交追踪，没有重生成历史样本或响应。

不把“事实”视为司法认定；原有“待人工核验”及引用支持关系人工判断均保留。

## 安全失败诊断

分类错误保留既有错误消息和`output_validation_failed / evidence_binding`外层状态，额外写入回执`validation_diagnostic`：

```json
{
  "section": "facts",
  "item_index": 0,
  "item_index_base": 0,
  "source_id": "S006",
  "matched_markers": [
    "尚未核实"
  ],
  "rule": "fact_from_claim_or_unverified_context",
  "scope": "original_unit_prefix_sentence_and_continuation",
  "unit_index": 5,
  "scope_start": 0,
  "scope_end": 30
}
```

以上是本轮用既有模拟SIM_B目录半句构造非法分类后，由本地validator生成的真实离线诊断；不是DeepSeek响应或真实模型复测。实际坐标由程序从当前解析文本计算。无quote、条目正文、文件名、访问密码或原始模型输出；匹配词仅来自固定词表，不输出匹配词周围的原文。没有新增公开日志打印。所有坐标相对于当前unit，索引从0开始。

这是**分类失败**的新增诊断；其他既有时间/引文错误仍保留原错误说明，本轮不重构全部错误系统。
