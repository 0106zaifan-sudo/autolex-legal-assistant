# AutoLex 一周实施方案（待实施）

计划窗口：2026-11-06至11-12，北京时间。11月10日保留一个中期演示里程碑，11月12日形成作品集候选版本。以下全部是**计划、目标和验收标准，不是已经实现或实测的结果**。

本次只创建审查分支及文档/探针。后续业务开发继续从现有AI分支复用，不从main重新生成项目，不自动合并或部署。

## 1. 一周交付范围

作品集候选版本服务“辅助驾驶事故纠纷第一轮法务审查”：案件材料包 → 材料记载与主张 → 冲突时间线/证据缺口 → 受控法源检索 → 带引证的法律研究初稿 → 人工复核 → 报告。

第一周限定：8个自建、明确标识的模拟案件包，每包2–3份文档；手工核实的3–5份官方法源、约20–40个可定位法源片段；小范围受控单实例演示。数量是范围预算，不是现有数据量。实际收集不足时如实缩减并说明，不为凑数编造法规或案例。

暂不纳入：自动最终归责/赔偿比例、原始EDR/CAN解码、自动司法鉴定意见、互联网全量判例抓取、复杂多租户平台、自动法律效力裁决。图片/扫描页先提供覆盖提示与人工补录，OCR列第二周，不能把未识别区域当成不存在。

## 2. 复用与目标结构

保留`core.py`的公开函数及原41项回归；`app.py`仍为Streamlit入口；复用官方SDK、Secrets、额度、错误处理、导出和ZIP白名单。

拟新增小模块，不一次性重排整个仓库：

```text
case_schema.py          CaseBundle / DocumentSnapshot / Statement / EvidenceSpan
case_store.py           会话内案件边界、模拟案件包导入/安全快照
evidence.py            解析快照、稳定锚点、引用绑定与覆盖清单
knowledge_base.py       受控法源元数据、离线索引和可定位命中
legal_research.py       仅基于检索法源生成研究初稿的独立输出契约
report_export.py        初审报告DOCX、证据索引及原Excel兼容
knowledge/              已核验法源清单和合法可保存的正文快照
fixtures/cases/         仅含模拟案件包
evals/                 版本化样本、金标准、结果与指标
tools/run_eval.py      可复算评测入口
docs/portfolio/        作品集说明、架构、演示稿、实测边界
```

先确立数据契约，再在必要时从现有文件提取实现；避免大改文件布局导致现有功能回归。案件材料与法律知识库分开索引；事实分析现有禁止编法条的约束继续保留，法律研究使用单独契约而不是全局放开该限制。

## 5. 评测口径及目标（均为尚未测量的验收目标）

| 指标 | 定义和样本 | 目标 / 不通过时的处理 |
|---|---|---|
| 原文锚点有效性 | 所有输出引用满足doc/snapshot hash和起止字符回放，报告匹配条数/总引用条数 | 100%；任何错文件、错位置、篡改引文阻断候选发布 |
| 事件—时间绑定 | 预设绑定、未知时间、相反陈述与跨文档错绑用例，自动校验及人工核对 | 确定性负例100%拒绝；未知不补时间；不能以总体平均掩盖错绑 |
| 分类与支持关系 | 至少40条人工标注陈述，报告事实/主张/推断/待分类混淆矩阵；推断前提另行人工审阅 | 分类macro-F1目标≥0.85，已回答内容支持率目标≥0.95，同时报告覆盖率防止全拒答刷分；未达到则降级人工分拣并显示局限 |
| 法源检索Recall@5 | 20条已标注有答案问题，按案件/争点隔离，相关集合由人工核验；不混入10条无答案问题 | 目标≥0.80；必须附实际命中数、样本量和失败例，不外推真实案件效果 |
| 无法源拒答率 | 10条无材料/错误时效/跨案件输入 | 目标100%；未命中时不得生成具体法律依据 |
| 引用支持与版本 | 初稿逐段核对引用是否支持分析、版本是否覆盖事故时点；未知效力单列 | 引用ID/版本机械一致100%；适用推理仍人工核验，不以ID命中证明法律结论正确 |
| 资源与费用 | 记录实际API usage、墙钟耗时、失败次数、使用的价格版本（如已核实） | 不编预算单价；费用未知就不报金额。默认限额继续生效，mock运行不记为真实模型使用 |
| 报告一致性 | DOCX/Excel/JSON对比同一运行、引用和核验状态 | 100%对应；无来源内容不能在导出时升级为事实或已核验 |

以上小样本目标是作品集验收线，不是企业生产SLA。未跑真实模型就不填写模型效果和token费用，不把同一案多格式文件扩大样本数，不用留出集调参后仍当作独立测试。

## 6. 法源收集与法律研究规则

本次不添加任何真实法条正文或案例编号。下一阶段只从可核实的官方发布来源收集，例如国家法律法规数据库、最高人民法院及相关主管机关官网，并记录具体链接和获取时间。材料应覆盖辅助驾驶功能状态/提示、产品与使用者义务、证据与因果等争点；具体法律适用仍要结合事故时间、地域、车型/版本和合同材料核实，不能预设每案适用相同条款。

法源清单把法律、行政规范、标准、裁判材料和企业说明书分别标类型，企业说明书不是法律。已废止、尚未生效、版本无法确认的资料不能默认为现行法；案例仅在真实来源和内容人工核验后引用。测试可使用明确虚构的法源记录，但不能进入正式知识库或法务初稿。

研究初稿的定位是向法务人员提交复核清单及研究线索，保留相反观点和证据不足，不能代替律师意见、法院认定或司法鉴定。
