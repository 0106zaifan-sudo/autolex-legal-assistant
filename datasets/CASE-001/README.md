## 独立人工Gold

- [人工规范源gold_specs.json](gold_specs.json)：26项预期判断、支持原文、理由、禁止推断、测试类别，由助手依据设计独立拟定，不取自被测系统或程序判断。
- [可读版Gold Standard](standard/gold_standard.md)及[完整JSON](standard/gold_standard.json)：正式生成后从实际解析文本唯一定位，附原文件/快照/引文SHA、unit_index、位置与字符范围。
- [scenario.json](scenario.json)：统一人物、车辆、事故、材料形成顺序，以及可追溯的source_graph；[DESIGN.md](DESIGN.md)包含作者参考轴/偏移，仅用于作者一致性，不是证据层可知事实。

坐标是0基Python Unicode字符范围[start,end)，不是PDF字节或Word页面。fixture_case_id/evidence_id供可重复离线测试；在应用新建案件后case_id和全局source_id会变化，应以文件SHA＋解析快照＋坐标重新映射，不硬比较测试用ID。

Gold为助手拟定的人工评审规范草案，尚未经过外部法学/司法鉴定专家审核，不宣称专家已经逐项标注认证。作者T_REF=08:30:20和时钟偏移不能被系统当成材料已证明的真实时刻。本标准明确区分资料记载、当事人主张、条件推断、待核实项及证明力限制，不提供法律责任标准答案。

默认每小时5次、请求字节上限256000。五批总请求预算395701字节，不能在同一预算窗口都执行；建议分B01—B03与B04—B05两个窗口，间隔仍遵守至少30秒冷却。配置只是静态预检，**不代表当前真实额度充足、不提供付费授权，也不重置调用记录**。未来若人工决定真实测试，每批仍需单独确认文档与解析风险，核对实际剩余额度。

每批只有其所有支持材料都在场的Gold焦点可完整评议；缺少来源的条目列在deferred_missing_sources，不把其他批次/答案偷放进当前输入。汇总评议按同一案件跨批人工核查，不能假定当前模型一次看过全部八份。

## 可重复生成与校验

在该仓库安装既有requirements.txt依赖后执行（不需要API密钥）：

```bash
python tools/generate_case_001.py --check
python tools/generate_case_001.py --output /tmp/case001-rebuild
python -m unittest discover -s tests -p test_case001_dataset.py -v
```

固定随机种子20261109；随机标记只用于工件标识，技术剧情值人工固定，不随机漂移。PDF使用invariant，DOCX固定属性及ZIP成员时间/顺序/权限。同一依赖和Python/zlib运行时下逐字节可重复；环境版本在manifest中记录。跨依赖版本请在新目录生成并复核，不承诺不同渲染器/压缩器字节相同。技术创建元数据固定，不代表文内编制或案发时间。

`--check`只在内存重建并比较，不写数据；生成器拒绝覆盖不同内容、混入额外文件或经符号链接逃逸。不存在/不唯一/跨源块的Gold引用会直接失败，不模糊匹配或挑第一个。需要修改已冻结的数据时应另行版本化并人工审查，不能为了某个模型通过改Gold。

校验所有生成文件：

```bash
cd datasets/CASE-001/standard
sha256sum -c SHA256SUMS
```

这些是测试资料文件，不是V2.0-C“案件工作包ZIP”。请按批次从materials上传并归档，不将Gold目录或manifest当作工作包导入。

## 已验证与未覆盖

[离线报告](standard/offline_report.json)只确认解析、全部引用定位、批次预算和三项有限检查：1分钟字面差、发出/收到不同命题、八文档/数据隔离策略。其余23项语义Gold没有执行自动或人工语义验收，模型语义准确率为not_measured；没有真实或Mock模型响应验收。这三项有限检查的人工语义/专家复核同样未完成，不代表整项Gold验收。

当前已知不足：

- 保守候选构建只覆盖部分独立事件，available_candidate_ids不是模型选择结果，不能代表完整时间线；毫秒和EDR相对轴不能强行装成现有秒级绝对时间。
- PDF同一解析单元含客观记载、主张、后置解释时，事实分类或引用校验可能保守拒绝整批。本轮只做输入预检，**没有证明真实模型能通过整个输出校验**。
- 现有闭集规则不完整识别command_id关联、字段语义、来源依赖、二次引用及证明独立性。例如C03相反主张的后续段落可能因严格归属边界返回待核实；这不降低Gold的语义要求。
- 08:30/08:31的字面差可展示，但接报字段误作碰撞、原始时钟与真实时刻、ADAS碰撞时状态、声音/画面/感知真实性和责任仍需人工核查。
- 复杂扫描/版式/修订/指令干扰尚未生成，见[干扰版规划](COMPLEX_VARIANTS.md)。本版测试不是现实事故重建或司法鉴定有效性验证。

实际执行日志与总数见[TEST_REPORT.md](TEST_REPORT.md)。核心规则、main、现有V2.0-D分支及旧样本未改。生成器不打开任何配额库；全量回归中的原配额测试只使用临时测试数据库，不更新现有调用记录。本轮不读改Secrets、不调用真实模型、不部署、不合并。
