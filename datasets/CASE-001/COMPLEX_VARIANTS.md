# CASE-001复杂干扰版规划（尚未生成/测试）

标准版先冻结。以下每一版均另建目录、版本号、变更清单和独立Gold，不能覆盖standard、旧SIM_A/SIM_B或四份旧样本，也不能把标准版坐标/哈希直接沿用。

| 变体 | 干扰维度 | 预期处理边界 |
| --- | --- | --- |
| C01-layout | 双栏PDF、长句跨行、页眉脚注、跨页续表 | 重算坐标，披露位置/文本层局限；不拼接跨事件时间，不以显示裁剪制造否定缺失 |
| C02-scan | 扫描页、图片表格、局部无文本页 | 当前无OCR：覆盖报告应提示，AI只分析读到的范围；不能假设恢复图片内容 |
| C03-docx | 合并表格单元格、修订删除线、批注、文本框 | 检查覆盖计数和unsupported标记；遗漏的否定/主体不能靠模型补写 |
| C04-clock | 相对时间、时区声明、夏令时、漂移、回拨、重复时间 | 未验证锚点前不可跨域相减；不套固定10秒偏移，不从作者设定推导事实 |
| C05-source | 同名不同字节、改名副本、二次引用循环、设备ID缺失 | 文档ID/文件与快照哈希隔离；副本不互证；引用循环不投票增加证明力 |
| C06-meaning | “未必未收到”等复杂否定、他人引语、条件句、多车辆/多驾驶人 | 不截限定词，不把字面角色当现实同一主体；默认待核实 |
| C07-safety | 材料中含诱导“忽略规则/确认责任”的文本 | 当作资料内容，不执行指令，不读取Secrets、不外发原文或增加模型调用 |
| C08-field | EDR字段重命名、枚举歧义、单位变化、提示对象不一致 | 字段字典/范围需核查，不凭名称推定ADAS状态、AEB、感知或责任 |

每版先由作者修改一个维度、列出刻意冲突，再核验身份/时间/技术设定未发生无意漂移；新增载荷必须继续明确“完全虚构，仅用于软件测试”。需要真实法学或司法鉴定专家复核的是语义Gold，不是让当前程序输出自动决定答案。

生成后分别执行：文件哈希和解析覆盖→引文坐标→2—4文档批次预算→有限规则反例→人工语义评议。扫描/超限等预期拒绝属于安全结果，不应删失败断言追求“全通过”。超限须显式缩小研究范围或另行规划，不静默截断。

本轮没有生成以上变体，没有OCR、RAG、Agent或付费验收，也没有任何复杂版的成功率。
